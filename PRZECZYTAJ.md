# APEX Naval Command — kandydat Windows x64

To repozytorium źródeł, nie rozpakowany produkt. Pełna instrukcja po polsku: [PRZECZYTAJ-WINDOWS](tools/windows/PRZECZYTAJ-WINDOWS.md). Builder kopiuje ją do korzenia ZIP-a jako `PRZECZYTAJ.md`.

Archiwum kandydata: `APEX-NAVAL-COMMAND-Windows-x64.zip`. Rozpakuj całość, porównaj zaufaną sumę SHA-256 i użyj `APEX-Desktop\ApexDesktop.exe`; bez ręcznej instalacji runtime. Dane pozostają prywatne w `%LOCALAPPDATA%\APEX Trading AI`, poza wydaniem. Poświadczenia pokazuje tylko natywne okno; `--show-local-access` służy do ich ponownego wyświetlenia, bez rotacji. Nie wpisuj ich do URL ani argumentów.

Task5 to engineering candidate, nie końcowy odbiór użytkownika. Native first-run/modal/default-shell/browser acceptance pozostają Task6; finalna dostawa Task7. Prezentacja jest historyczna/syntetyczna, bez kont runtime, brokerskiego odbioru lub zgody na transakcje. Zamknięcie karty/procesu nie zastępuje finansowego STOP. Nie osłabiaj ACL ani nie wystawiaj portów loopback.
